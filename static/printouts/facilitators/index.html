Aerospace Jam

Facilitators

Run the arena conversation and keep the live match timing accurate.

Your Mission

Welcome the team, guide the judging flow, and press the timing buttons at the real start and real end of each run.

You Will Use

Facilitator Dashboard Queue Start End End + Advance
1

Before The First Team

  1. Log in.
  2. Confirm your arena number.
  3. Check the next few teams.
  4. Make sure the arena is ready.
2

For Every Team

  1. Welcome the team.
  2. Press Queue when they are on deck.
  3. Press Start when the run truly begins.
  4. Guide the discussion category by category.
3

When The Run Ends

  1. Press End when the run truly ends.
  2. Use End + Advance if the next team starts right away.
  3. Keep the arena moving.

Say It Like This

  • "Welcome team, we are starting now."
  • "Let's go one category at a time."
  • "Judges, ready for the next section?"
  • "Thank you, that run is complete."

Never Do This

  • Do not score for the judges.
  • Do not forget Start and End.
  • Do not wait until later to fix timing.
  • Do not argue with teams about scoring.
