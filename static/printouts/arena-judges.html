Aerospace Jam

Arena Judges

Score the arena run fairly, calmly, and together on one shared device.

Your Mission

Watch the run, discuss each score as a pair, enter one agreed answer, and save only after both judges are satisfied.

You Will Use

Judge Login Judging Score Form Save
1

Before The First Team

  1. Log in.
  2. Open the judging page.
  3. Confirm the correct arena.
  4. Choose one device driver.
  5. Choose one final checker.
2

For Every Team

  1. Open the correct team.
  2. Watch the run carefully.
  3. Talk through each score.
  4. Enter the agreed answer.
  5. Double-check before save.
3

Before You Move On

  1. Add a short note if needed.
  2. Save the form.
  3. Make sure the score is complete.
  4. Then prepare for the next team.

If Something Feels Off

  • Pause.
  • Re-read the category.
  • Ask the facilitator to clarify.
  • Agree on one final score.
  • Then save.

Never Do This

  • Do not save without agreement.
  • Do not rush because another team is waiting.
  • Do not manage the queue.
  • Do not leave a score half-finished.
