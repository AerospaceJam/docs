# Printable Cards

If you want something you can laminate, tape to a clipboard, or hand to a volunteer during training, these print-ready cards are the quickest version of the ASJudge role guides.

Each card is designed as a one-page handout. For best results, print on letter paper at 100% scale with background graphics enabled. Default or minimum margins usually work well.
